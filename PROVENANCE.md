# Airdraft provenance

The source checkout preserves NekoDrop v0.1.35 history at `cc1d8061d07b5894346c28ba74f0c7597feba309`. NekoDrop uses GPL-2.0 for its application and Intel radio. Keep its license text, per-file notices and contributor credits. The Airdraft tray is GPL-2.0-only. The register proxy and Python engine retain their upstream MIT notices. Airdraft changes the service's desktop ownership, restricts the preview to the AX210 PCI ID, builds a native Win32 tray, patches receive visibility and file publication in the existing AirDrop engine, assigns unique names to files within outgoing batches, and stages the preview.

The unmodified upstream baseline additionally pins [devourer](https://github.com/raph559/devourer/tree/8d936de2a3805ce126e5236349afe40e645aaf9b) at `8d936de2a3805ce126e5236349afe40e645aaf9b` for RTL8852CE. The AX210 preview does not include that radio.

The separate RTL8852BE development target fetches Orchard at `4f6d1e93fdd002aba08d028a803372cb706fa9ec` under GPL-2.0. Its RTL8852BE PCIe code cites Linux rtw89 at `734bef548a96e8774d6eef5dfa2026c6edc4e80b`. The build adapts the pinned winawdl radio to opt into Orchard's BE implementation, accepts the `10EC:B852` and `10EC:B85B` PCI IDs used by Linux's RTL8852BE driver, and requests radio shutdown when the Airdraft service closes its control pipe. It retains the shared AX PCIe DMA plane and builds the RTL8852B firmware and chip-specific calibration sources for this target. The two embedded RTL8852B firmware images come from Realtek's vendor driver via Orchard's extractors. Redistribution of the development build and its embedded firmware requires a separate notice and license review. [Orchard source](https://github.com/orchard-win/orchard-devourer/tree/4f6d1e93fdd002aba08d028a803372cb706fa9ec), [Linux RTL8852BE PCI table](https://github.com/torvalds/linux/blob/master/drivers/net/wireless/realtek/rtw89/rtw8852be.c)

Keep the corresponding source, including Airdraft's actual changes and build scripts, with any redistributed preview. Distribute the original notices from each package as shipped.
